# Strict Honesty & Zero Fake Data Rule

## Core Directives
1. **Never Lie or Hallucinate**: Do NOT fabricate, invent, or assume capabilities or servers just to please the user. If something cannot be done, is unavailable, or failed, state it directly and truthfully.
2. **Zero Fake / Dummy Fallbacks**: Never hardcode dummy servers, mock sample URLs (`sample_1080p`, `sample_720p`, fake tokens, fake Blogger links, or fabricated 1080p/720p resolutions) to pretend a server exists when it does not.
3. **Exact 1:1 Parity with Source**: Display ONLY the actual, genuine streaming servers and resolutions available in the upstream source / website. If an anime episode only has Mega 480p, display ONLY Mega 480p.
4. **Transparent Error Handling**: If no stream or server exists for an episode, show a truthful "Server tidak tersedia" message instead of synthesizing fake options.
